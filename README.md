Under The Crust – Pie Map 🍽️🥧
This project generates an interactive, shareable HTML map showing pie shops and pie-related venues across Nottinghamshire, with rich popups, custom icons, and intelligent clustering for Nottingham city.
The output is a single file—index.html—that can be opened in a browser or deployed as a static website (GitHub Pages, Netlify, etc.).

What This Script Produces
✅ An interactive Leaflet / Folium map
✅ Custom pie icons per location (Base64-embedded, no external assets needed)
✅ Instagram embeds inside popups
✅ Website & Google Maps directions links
✅ Nottinghamshire county boundary overlay
✅ Automatic clustering of Nottingham city locations
✅ Mobile-friendly with favicon & PWA metadata

Final Result
When the script is run:

index.html is generated in the project root
Opening this file displays:

A styled Stadia Maps basemap
Pie locations as custom image markers
Clustered markers within Nottingham city
Individual markers elsewhere in the county
Clickable popups with embedded content

No backend or server is required after generation.
